# Pomodoro Timer

Um timer Pomodoro simples desenvolvido para auxiliar na gestão de tempo e foco durante estudos ou trabalho.

## Tecnologias Utilizadas

- **HTML5**: Estruturação dos elementos visuais.
- **CSS3**: Estilização e layout.
- **JavaScript**: Lógica de contagem regressiva, controle de tempo e manipulação do DOM.

## Funcionalidades

- **Start**: Inicia a contagem regressiva de 25 minutos (impede a aceleração com múltiplos cliques).
- **Pause**: Congela a contagem no tempo exato em que foi pausado.
- **Reset**: Interrompe a contagem e retorna a tela para o tempo inicial (`25:00`).
- **Formatação MM:SS**: Exibição dos dígitos com zero à esquerda usando `padStart`.

# Pomodoro Timer

A simple Pomodoro timer built to help with time management and focus during study or work sessions.

## Technologies Used

- **HTML5**: Page structure and elements.
- **CSS3**: Layout and styling.
- **JavaScript**: Countdown logic, timer controls, and DOM manipulation.

## Features

- **Start**: Begins the 25-minute countdown (prevents timer speed-up from multiple clicks).
- **Pause**: Pauses the timer at the current remaining time.
- **Reset**: Stops the countdown and restores the display to `25:00`.
- **MM:SS Formatting**: Displays digits with leading zeros using `padStart`.
